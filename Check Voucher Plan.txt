Check Voucher (Sales)

The Excel workbook is a monthly check-voucher pack: sheet CV MONITORING (register) plus one sheet per voucher (340–380) matching the screenshot (CVNO. 2026-M-380). There is no voucher feature in the app yet. Implement it next to Petty Cash in templates/sales_dashboard.html, following Ageing / Petty Cash (DB + live preview + PDF archive).

Document layout (match screenshot)

Fixed letterhead: METRO DAVAO SUPREME PUMPS INDUSTRIES, INC. / #406 DIAMOND ST., SAN JUAN SUBD., PANACAN, DAVAO CITY.

Form fields:

CVNO — 2026-M-380 style; auto-suggest next number (YYYY-M-{n}) from existing records

DATE, PAYEE

Debit lines — description + debit amount (e.g. BILLING NO. 26-1175 / 85,687.38; also PURCHASES, INPUT TAX, MEALS & LODGING, etc.)

CASH IN BANK credit — defaults to debit total

TOTALS — debit = credit

Payment for (text; often payee or purpose)

Received from MDSPII, Check Amount (= total)

Check no. + Bank (BANK: MBTC/RCBC/PBB or similar)

Received by + signature line

Prepared / Checked / Approved labels with default names: Angelmarie M. Dapar, Ms. Beverly Tan, Ms. Christine Joy Ilogon, Engr. Arturo I Davis, PME


Typography (copy Excel fonts)

Sheet 380 (the screenshot form) uses Century Gothic only. Apply the same face and sizes on .cv-doc preview, print, and PDF (html2canvas uses the rendered CSS). Encoder inputs can stay dashboard UI fonts.

CSS: font-family: "Century Gothic", CenturyGothic, "AppleGothic", sans-serif on the voucher document. On Windows this matches the workbook; no substitute display font for the preview.
